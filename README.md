# まちマニアMAP

日本じゅうの町を歩いて、お店に出会える 3D マップです。お店に近づくと情報カードが出て、動画や写真を見られます。ほかの人と同じ町を歩き、チャットやスタンプで話せます。

- 地図：全国 1,902 の市区町村と都道府県の境、鉄道約 650 路線・約 9,000 駅、海・砂浜（縮尺は実際の約 1/40）
- 町のにぎわい：季節で色が変わる木（いまの月に合わせる）、森・花畑・畑、川沿いと大通りの並木、駅舎と駅前広場、まちの人、電車、鳥
- 公開：GitHub Pages（無料）＋ Supabase（無料プラン）

## お店の色とモード

| 色 | 意味 | だれが登録するか |
|---|---|---|
| 黄 | まちマニア横塚（動画で紹介したお店） | あなた（`data/shops.json`） |
| 赤 | 新店（オープン1年以内の**個人オーナー店**。チェーン・フランチャイズ・企業運営の店は入れない） | 毎日の自動リサーチ → スプレッドシート「新店」シート（`data/research.json`）。手動なら `data/shops.json` |
| 紫 | 開店1年以上（赤のお店が1年たつと自動で変わる） | － |
| 青 | 参加者投稿（口コミ。SNS投稿のリンクもつけられる） | 参加者（町の中の「投稿」ボタン） |

| モード | 見えるお店 |
|---|---|
| スタンダード | すべて |
| 新規出店収集 | 赤・紫 |
| みんなでつくるMAP | 黄・青 |
| 投稿ランキング | 青（口コミ投稿数の多い人のランキングを表示） |

## そのほかの機能

- **電車・飛行機・船**：駅・空港（30か所）・港（21か所、11航路）に近づくと「乗る」ボタンが出ます。電車は路線と行き先を選ぶと線路に沿って走り、新幹線は高架を走ります。飛行機は日本列島を見下ろしながら飛び、船は航路に沿って進みます。空港・港・航路は `data/transport.json` で増やせます
- **ナビ**：みんなのアバターに、小さな光（ナビ）がついて歩きます。まちマニア横塚さんのナビは金色です
- **ナビの案内**：はじめて来た人には、ナビが使い方を順番に説明します。右上の「？（ナビ）」ボタンで、知りたいことを選んでいつでも聞けます
- **まちマニア横塚さんの★**：本人のアバターには★と「公式・本人」の名札がつき、チャットの名前にも★がつきます。「まちマニア」「横塚」を含む名前は本人以外は使えません
- **地域ごとの部屋**：位置とチャットは、同じ地域（地図のタイル1枚、約80km四方）にいる人どうしだけでやり取りします。ひとりのときは位置を送りません
- **入室待ち**：全国の同時接続が190人をこえると、新しく来た人は入室待ちの画面になり、30秒ごとに自動で入りなおします（待つ間もひとりで歩けます）
- **アカウント**：**ニックネーム＋パスワード**だけで参加できます（メールアドレスは使いません）。はじめて開くと登録画面が出ます。登録しないゲストは町を歩いて見ることだけでき、チャットと投稿は登録した人だけです
  - 一度ログインすると、その端末ではずっとログインしたまま。別の端末では同じニックネームとパスワードでログイン
  - パスワードは Supabase の認証が一方向の暗号（ハッシュ）にして持つだけで、運営も見られません。**忘れたら再発行はできず、アカウントの作り直し**です
  - ニックネームは重複できません（全角・半角などのちがいも同じ名前とみなします）。ログイン名なので、あとから変えられません
- **投稿数とランキング**：自分の投稿数は左上の「📝 あなたの投稿」に表示。押すか「投稿ランキング」モードで、投稿数の多い人のランキングが見られます。スプレッドシートの「アカウント」シートにも投稿数が記録されます
- **顔写真からアバター**：「すがた」→「顔写真から似せてつくる」で、はだ・かみの色・かみの長さ・目と口の感じを写真に寄せます。写真は端末のブラウザの中だけで読み取り、**送信も保存もしません**（顔の位置を見つける部品 MediaPipe は、使うときだけ読み込みます）
- **まちマニア横塚さん専用のすがた**：★の公式アカウントは、えらんだ見た目にかかわらず専用のすがた（首からカメラ）になります。参加者は選べません。見た目は `js/avatar.js` の `OWNER_LOOK` で変えられます
- **スマホ版**：同じページがスマホの画面に合わせて変わります。ホーム画面に追加すると、アプリのように全画面で開けます（iPhone は Safari の共有 →「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」）

## 1. GitHub Pages で公開する（無料）

ファイルが 190 個ほどあり、GitHub の画面からのアップロード（1回100個まで）では入りきらないので、**GitHub Desktop（無料）** を使います。

1. GitHub で新しいリポジトリを作る（名前は例：`machimania-map`、Public）
2. GitHub Desktop で「Clone a repository」→ いま作ったリポジトリを選び、パソコンに取り込む
3. 取り込んだフォルダに、このフォルダの中身を全部コピー（`.github` と `.nojekyll` は隠しファイルなので、見えないときは表示を切り替えてください）
4. GitHub Desktop に戻り、左下に「最初の公開」などと書いて「Commit to main」→「Push origin」
5. GitHub の「Settings」→「Pages」→ Branch を `main`、フォルダを `/ (root)` にして「Save」
6. 1〜2分で `https://（ユーザー名）.github.io/machimania-map/` が開けるようになります

この時点では **テストモード** です。会えるのは同じブラウザの別タブとテスト住人だけで、投稿はその端末にだけ保存されます。

## 2. Supabase でオンラインにする（無料）

1. https://supabase.com でアカウントを作り、「New project」（Region は Tokyo がおすすめ）
2. 左メニュー「SQL Editor」→ `supabase/schema.sql` の中身を全部貼って「Run」（チャット・投稿の置き場所がまとめて作られます。以前の版を実行ずみでも、もう一度実行すれば更新されます）
3. 「Authentication」→「Sign In / Providers」で
   - **Allow anonymous sign-ins** をオン（登録しないゲストが町を見るため）
   - **Email** をオンのまま、**Confirm email をオフ**（ニックネーム＋パスワードの登録に使います。メールは送られません）
4. 「Authentication」→「URL Configuration」で、Site URL に GitHub Pages の URL を入れる
5. 「Project Settings」→「API」で **Project URL** と **anon public key** をコピーし、`js/config.js` の `supabaseUrl` と `supabaseAnonKey` に貼って Commit
6. **★（公式・本人）マーク**：設定が終わったら、**だれよりも先に**町を開いて、ニックネーム「まちマニア横塚」でアカウントを作ってください。最初にこの名前で登録した人が自動で公式（★）になり、以後この名前（「まちマニア」「横塚」を含む名前）はほかの人は使えません
7. （あとで使います）**あなたを運営者にする**：Supabase の「Authentication」→「Users」で自分の行の UID をコピー →「Table Editor」→ `admins` に1行追加して `user_id` に貼る

> 登録で「メールアドレスの形式が正しくない」というエラーが出るときは、`js/config.js` の `accountIdDomain` を別の値（例：`users.machimania.example`）に変えてください。これはログイン用の内部IDで、メールは送られません。変えると、それまでのアカウントにはログインできなくなるので、最初に決めてください。

## 3. 参加者の投稿（青いお店）

写真や動画は**こちらでは保存しません**。

- 投稿できるのはアカウントを作った人だけ。町の中で「📷 投稿」を押し、**いま立っている場所**（または緯度・経度）にお店を建てます
- **口コミ（必須・10文字以上・200文字まで）**＋ **SNS投稿のリンク（おすすめ・なくてもOK）**。リンクは Instagram・TikTok・YouTube・X・Facebook・Threads の公開投稿で、各SNSの公式の埋め込みで表示します
- 投稿者名はアカウントのニックネーム。投稿は **すぐに公開** され、町にいるほかの人の画面にもその場で建ちます（承認制はありません）
- **口コミのルール**：味・量・値段・接客・待ち時間・清潔さなどの感想は、マイナス評価でも率直なまま載せます。**人やお店の尊厳を傷つける投稿**（暴言、見下す言葉、差別的な言葉、根拠のない犯罪の決めつけ、お店の人への人格攻撃、個人を晒すこと）は、画面とデータベースの両方でチェックして投稿できないようにしています。チェックの言葉は `js/moderation.js` の `ABUSE_RULES` と `supabase/schema.sql` の `review_is_abusive` で直せます（両方そろえて直してください）
- すり抜けた投稿は、スプレッドシートの「投稿」シートで「状態」を「非表示」にすると、次の同期（1時間ごと）で町から消えます
- 1人1日10件まで。問題のある投稿は通報でき、「アカウント」シートで「利用停止」にした人は投稿もチャットもできなくなります
- 保存するのは文字（リンク・店名・ニックネーム・口コミ）だけなので、1件あたり約1KB。Supabase の無料データベース（500MB）で数十万件入ります

## 4. あなたのお店を追加する（黄・赤）

1. `https://（ユーザー名）.github.io/machimania-map/shop-form.html` を開く
2. 種類（YouTube で紹介／リサーチした新店）を選び、店名・場所（Googleマップで右クリックして出る「35.54132, 139.44836」のような数字）などを入れる
   - YouTube：リンク・公開日・ひとこと
   - 新店：オープン日・概要・背景・情報源の URL（オープン日から1年で自動で紫になります）
3. 「全部コピー」→ GitHub で `data/shops.json` を開いて えんぴつ → 中身を全部置きかえて Commit
4. 1〜2分後に町を開き直すと、お店と、そのまわりの木や花が建っています

最初に入っている赤と紫のお店はサンプルです。登録ページで1軒作ると、サンプルは自動で外れます。

## 5. スプレッドシートで管理する（新店・投稿・アカウント）

管理用スプレッドシートに `apps-script/Code.gs` を入れると、次のシートが自動で動きます。

| シート | 中身 | あなたがすること |
|---|---|---|
| 新店 | 毎日の自動リサーチで見つかった**個人オーナーの**新店（「個人店の根拠」列つき）。「状態」は開店日から自動で「新店／1年以上」 | MAPに出したくない行は「表示」のチェックを外す。手で行を足してもOK |
| 投稿 | 参加者の投稿（1時間ごと） | 問題のある投稿は「状態」を「非表示」にする（次の同期でMAPから消える） |
| アカウント | ニックネーム・投稿数・登録日・最終ログイン（1時間ごと。メールアドレスやパスワードは持たない） | 「利用停止」にチェックで投稿・チャット禁止、「公式★」で★マーク |
| 通報 | 参加者からの通報 | 見て判断する |
| ログ | 自動処理の記録 | － |

**参加者の情報が入るので、シートの共有は「制限付き」のままにしてください。**

設定のしかた：

1. スプレッドシートで「拡張機能」→「Apps Script」→ `apps-script/Code.gs` の中身を全部貼って保存
2. 左の歯車「プロジェクトの設定」→「スクリプト プロパティ」に4つ追加
   - `GITHUB_REPO`：`（ユーザー名）/machimania-map`
   - `GITHUB_TOKEN`（なくても動きます。入れるとシートの変更が翌朝を待たずにすぐMAPに出ます）：GitHub の Settings → Developer settings → Fine-grained tokens で、このリポジトリだけ・Contents を Read and write にしたトークン
   - `SUPABASE_URL`：Supabase の Project URL
   - `SUPABASE_SERVICE_KEY`：Supabase の Project Settings → API の **service_role** key（ここ以外には貼らない）
3. 関数 `setup` を選んで「実行」→ Google の許可画面で許可
4. 以後、毎朝7時台に新店、1時間ごとに投稿・アカウントが自動更新。シートの「まちマニアMAP」メニューから今すぐ実行もできます

### 毎日の新店リサーチ

流れ（毎日）：
1. **5:43** Claude のスケジュール実行が、シートの「新店」で表示にチェックのある行を `data/research.json` に書き出す（→ MAP に赤いお店が建つ）。続けて全国の新店を調べ、信頼できる情報源・住所・開店日がそろったものだけを `data/research-inbox.json` に追加（指示文は `tools/daily-research-prompt.md`）
2. **7時台** Apps Script が受け箱を「新店」シートに取りこむ。緯度・経度は住所から国土地理院の住所検索で自動で付く
3. あなたは日中、シートで気になる行の「表示」チェックを外したり、内容を直したりする → 翌朝の 1 で MAP に反映

`GITHUB_TOKEN` を入れておくと、2 の時点ですぐ MAP にも反映されます（翌朝を待たない）。開店日から1年たつと、MAPでもシートでも自動で紫（1年以上）になります。

## 6. 地図をくわしくする（GitHub Actions）

いまの地図は、この作業環境から取れたデータで作っています。

- 関東以外の線路は、**駅と駅をまっすぐつないだ線**です
- 道路は **町田市の主な道路だけ（仮の配置）** です

本物の線路の形（国土数値情報）と、全国の主な道路・川（OpenStreetMap）に置きかえるには：

1. GitHub の「Actions」タブ →（初回は有効化）→ 左の「地図データを作る」→「Run workflow」
2. 全国ぶんなので 30分〜1時間ほどかかります。終わると `data/japan` が自動で更新されます
3. お店のまわり（半径約3km）は細い道路まで取り込みます。お店が増えたら、ときどき実行してください

うまく取れなかった部分は、自動でいまのデータのまま残ります。

## 無料枠について

写真や動画のアップロードはないので、保存容量（ストレージ）は使いません。使うのは次の4つです。

| サービス | 無料の範囲 | このMAPで使うもの |
|---|---|---|
| Supabase リアルタイム通信 | 月200万メッセージ・同時接続200人 | **いちばん使う**。同じ地域にいる人どうしの位置（1秒に2回・ひとりのときは送らない）・チャット・スタンプ・新しい投稿の知らせ。1回送ると「送った1回＋受け取った人数」と数えます |
| Supabase データベース | 500MB | 投稿・チャット履歴・プロフィール（文字だけなので1件約1KB） |
| Supabase データ転送 | 月5GB | 町を開いたときに投稿やチャット履歴を読み込む分 |
| GitHub Pages | 月100GB | 画面と地図データ（1人が町を開くと、まわりの地図で数MB） |

めやす（歩いている時間を半分として）：同じ地域に2人なら1時間で約1.4万、5人なら約9万、10人なら約36万メッセージ。ひとりなら0です。同じ場所に大勢が集まる使い方が増えたら、位置のやり取りだけ Cloudflare に移すと、無料のまま大幅に増やせます。Supabase は7日間だれも開かないと一時停止します（データは消えません）。

## 7. 安全のための仕組み

- チャット：100文字まで・連投制限・リンク／メール／電話番号の自動伏せ字・一部の言葉の伏せ字（`js/moderation.js` の `NG_WORDS` に追加できます）
- 名前をタップしてブロック・通報。お店カードから投稿の通報
- 通報は Supabase の `reports` テーブルで確認できます

> 知らない人同士がメッセージをやり取りできるサービスは、無料でも日本の電気通信事業法の届出が必要になる場合があります。一般公開の前に、総務省の案内などで確認してください。
